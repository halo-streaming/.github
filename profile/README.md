# halo: a decentralized, fast streaming protocol

*halo* is a new peer-to peer protocol that enables low-latency encrypted video streaming, leveraging state-of-the-art technologies such as the Media-over-QUIC (MoQ) protocol layered on top of QUIC and UDP.
